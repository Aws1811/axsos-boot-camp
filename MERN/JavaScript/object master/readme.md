# Object Master


## Run the app
Open the file in your browser console or run it with Node.js:
```
node objectMaster.js
```

## Built With
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) — programming language

## Features
- Work with a frozen immutable array of Pokémon objects using `Object.freeze`
- Filter Pokémon whose id is evenly divisible by 3
- Filter Pokémon that are "fire" type
- Filter Pokémon that have more than one type
- Map all Pokémon to an array of just their names
- Filter and map Pokémon with an id greater than 99 to get their names
- Filter and map Pokémon whose only type is poison to get their names
- Filter Pokémon whose second type is "flying" and map to their first type
- Count the number of Pokémon that are "normal" type
