# Its Time to Duel


## Run the app
Open the file in your browser console or run it with Node.js:
```
node duel.js
```

## Built With
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) — programming language

## Features
- Create Unit cards (Red Belt Ninja, Black Belt Ninja) with power and resistance stats
- Create Effect cards that increase or decrease a Unit's resistance or power
- Apply effects to units and log stat changes before and after
- Attack a target unit and reduce its resistance by the attacker's power
- Test all interactions between cards and log the full results to the console
