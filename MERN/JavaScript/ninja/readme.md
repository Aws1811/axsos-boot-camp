# Ninja Classes

## Preview
No photos provided for this assignment.

## Run the app
Open the file in your browser console or run it with Node.js:
```
node ninja.js
```

## Built With
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) — programming language

## Features
- Create a Ninja class with name, health, speed, and strength attributes
- Display a ninja's name and full stats using class methods
- Increase a ninja's health by drinking sake
- Extend Ninja with a Sensei class using inheritance, with boosted stats and a wisdom attribute
- Override parent stats in the Sensei constructor using `super`
- Call inherited methods from the parent class inside the child class
