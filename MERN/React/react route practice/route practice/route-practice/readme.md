## Run the app

```
# 1. install dependencies
npm install

# 2. run the development server
npm run dev
```

Then open your browser at: `http://localhost:5173`

## Built With

- [React](https://react.dev/) — JavaScript UI library
- [React Router](https://reactrouter.com/) — client-side routing
- [Vite](https://vitejs.dev/) — frontend build tool

## Features

- Set up client-side routing using `Routes` and `Route` from React Router
- Display a home page at `/home`
- Show a dynamic number from the URL at `/Number/:id` using `useParams`
- Show a dynamic word from the URL at `/:word` using `useParams`
- Render a styled heading at `/:word1/:background/:color` using URL params to set text content, background color, and font color
