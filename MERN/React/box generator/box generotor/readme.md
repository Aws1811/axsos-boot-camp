## Run the app

```
# 1. install dependencies
npm install

# 2. run the development server
npm run dev
```

Then open your browser at: `http://localhost:5173`

## Built With

- [React](https://react.dev/) — JavaScript UI library
- [Vite](https://vitejs.dev/) — frontend build tool

## Features

- Enter a color name in a form and submit to add a new colored box
- Dynamically render colored boxes using inline styles based on user input
- Store all added colors in state using the spread operator
- Clear the input field after each submission
