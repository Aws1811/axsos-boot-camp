## Run the app
```
# 1. install dependencies
npm install

# 2. run the development server
npm run dev
```
Then open your browser at: `http://localhost:5173`

## Built With
- [React](https://react.dev/) — JavaScript UI library
- [Vite](https://vitejs.dev/) — frontend build tool

## Features
- Create a reusable `PersonCard` component that accepts `firstName`, `lastName`, `age`, and `hairColor` as props
- Display four unique person cards using the same component with different prop values
- Destructure props inside the component for cleaner JSX
