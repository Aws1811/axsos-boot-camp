# Five Heads

## Preview

No photos provided for this assignment.

## Run the app

Open the file in your browser console or run it with Node.js:

```
node script.js
```

## Built With

- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) — programming language

## Features

- Simulate a coin toss that randomly returns "head" or "tail"
- Wrap the logic in a Promise that resolves when five consecutive heads are flipped
- Count and log every flip and track the total number of attempts
- Chain `.then()` to display the final result and `.catch()` to handle any errors
- Demonstrate that synchronous code after a Promise runs before the Promise resolves
